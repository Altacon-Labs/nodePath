# Security reporting

This scaffold is development-only and has no supported production release. Do not deploy it with real customer data before the production requirements in docs/architecture.md are implemented.

Do not report exploitable vulnerabilities in public issues. If GitHub private vulnerability reporting is enabled, use the repository Security tab to report privately. Otherwise contact the repository owner through a private channel listed on their profile. No private reporting address or response SLA was supplied, so none is invented here. Repository owners should enable private vulnerability reporting before inviting broad adoption.

Include affected commit, reproduction steps, impact and a suggested fix where possible. Never include credentials or real user data.
