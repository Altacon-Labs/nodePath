# Community conduct

Be respectful, constructive and welcoming. Critique work, not people. Harassment, discrimination, threats, doxxing and publishing private information are unacceptable in issues, pull requests and other project spaces.

Project owners are responsible for moderation and may edit or remove harmful content or restrict participation. For non-sensitive concerns use a repository issue. For sensitive concerns use a private owner contact listed on the repository owner's profile; do not post private information publicly. Owners should publish a dedicated confidential contact before promoting the project to a wider community.
